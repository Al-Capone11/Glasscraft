# Glasscraft

Multiloader (Fabric + NeoForge) Minecraft 26.2 mod: a Glasscutter that safely harvests
glass, panes, glowstone and sea lanterns, OptiFine-style connected glass textures (CTM),
optional clean glass, and Jade support.

## Branches
- `main` - project overview
- `mc/26.2` - development for Minecraft 26.2
